# Bidding

Gestionnaire des enchères au bridge selon le Système d'Enchère Français (SEF 2024).

## Description

Le projet permet de jouer au bridge, les autres joueurs sont gérés par le logiciel. Il distribue des donnes aléatoires, effectue les enchères selon le SEF 2024, et gère le jeu de la carte.
